# Security Policy

## Supported versions

fleurıs is actively evolving. Security fixes are generally applied to the latest version of the project.

| Version | Supported |
| --- | --- |
| Latest | Yes |
| Older versions | Best effort |

## Reporting a vulnerability

If you believe you have found a security vulnerability in fleurıs, please report it privately and responsibly.

- **Do not** open a public issue for a suspected security problem.
- Share a clear description of the issue, the steps to reproduce it, and the potential impact.
- If possible, include screenshots, proof-of-concept details, or suggestions for a fix.
- Use a private reporting channel provided by the repository maintainers/host (such as a private security advisory, if available). If no private channel is available, contact the maintainers directly and ask for a secure way to share details.

## What to expect

- Maintainers will review the report as soon as practical.
- You may be asked for additional information to help reproduce or understand the issue.
- Once confirmed, maintainers will work on a fix and coordinate disclosure in a way that helps protect users.

## Security approach

fleurıs is designed to be simple and user-controlled. When using the app, keep these good practices in mind:

- Keep personal copies/backups of important work.
- Be careful when opening or importing files from sources you do not trust.
- Use trusted devices and browsers when working with private information.

Thank you for helping keep fleurıs and its users safe.
