# Contributing to fleurıs

Thank you for your interest in fleurıs. Feedback and ideas are welcome, but please note that the project’s [license](./LICENSE) allows viewing and using the software while **not permitting modification, changes, removal of existing code, or redistribution** without prior written permission from the copyright holder.

## Ways to help

- **Report bugs:** describe what happened, what you expected, and how to reproduce it.
- **Suggest improvements:** share the problem you’re facing and how a change could help.
- **Share feedback:** let the maintainers know what feels confusing, missing, or especially useful.
- **Ask permission for changes:** if you would like to propose or make code/documentation changes, contact the copyright holder first to request permission.

## Before opening an issue

- Check existing issues and discussions to avoid duplicates.
- Keep reports clear, respectful, and focused on the user problem.
- Include steps, screenshots, or examples when they help explain the issue.


Please do not submit pull requests that modify, change, or remove existing code unless you have prior written permission.

## Community expectations

By participating in this project, you agree to follow the [Code of Conduct](./CODE_OF_CONDUCT.md).

## Questions

If you’re unsure about what is allowed, open an issue or contact the maintainers/copyright holder for clarification.
